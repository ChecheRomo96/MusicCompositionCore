Detailed Description

Absolute semitone position of a pitch, with origin C-1 = 0.

C0 = 12, C4 = 60 and A4 = 69 (SPEC-CHR-1). Valid values cover every writable pitch, from Cbbbb-128 = -1528 to B####127 = 1551 (SPEC-CHR-2); they are not restricted to any protocol range (SPEC-CHR-3).

Default construction and out-of-range input produce the single invalid value (SPEC-ERR-2, SPEC-ERR-3). Indices are ordered by value; the invalid value sorts after every valid index.

Detailed Description

Directed intervals and spelling-preserving transposition.

MCC::Interval stores a diatonic step count and a semitone count, from which its MCC::IntervalDirection, MCC::IntervalNumber and MCC::IntervalQuality are derived. MCC::IntervalBetween() measures the interval between two pitches or note names, and pitch + interval transposes while preserving spelling: E4 + M3 = G#4, never Ab4. See Music-Domain Specification (SPEC-INT-*).

Available when MCC_INTERVAL is defined. Requires the Pitch module.

enum class MCC::IntervalDirection : int8_t
strong

Direction of an interval (SPEC-INT-2).

The direction follows the written letters: an interval whose second letter is higher is ascending even if it is a diminished interval. Only the perfect unison has direction Unison; an augmented unison is ascending or descending (SPEC-INT-5).

Returns the directed interval from from to to (SPEC-INT-1): the difference of their diatonic and chromatic indices. B#3 to C4 is an ascending diminished second; C4 to Cb4 is a descending augmented unison (SPEC-INT-5).

The result is invalid when either pitch is invalid or the quality would need more than four augmentations or diminutions (for example Cbbbb4 to C####4).

Detailed Description

Exact written note length: a power-of-two base and zero to four dots.

A note value is independent of tempo, clocks and PPQN. Its duration is an exact reduced fraction of a whole note: a quarter note is 1/4, a dotted quarter is 3/8, and a double-dotted quarter is 7/16.

Default construction and invalid factories produce the single invalid value. Invalid values return 0/0 from Numerator() and Denominator().

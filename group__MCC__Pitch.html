Detailed Description

Written pitch primitives: letters, accidentals, note names and pitches.

MCC::Letter + MCC::Accidental form a MCC::NoteName, which keeps its written spelling, and a note name plus an octave forms a MCC::Pitch (middle C is C4). MCC::PitchClass and MCC::ChromaticIndex discard the spelling and are obtained explicitly. Written equality and order are separate from enharmonic equivalence and pitch height; see Music-Domain Specification.

All types are trivially copyable, allocation-free and constexpr. Available when MCC_PITCH is defined.

enum class MCC::Letter : uint8_t
strong

Diatonic letter name.

Closed enumeration ordered C D E F G A B with diatonic indices 0-6 (SPEC-ORD-1). Every enumerator is valid; Letter has no invalid state (SPEC-ERR-1). Values produced by casting integers outside 0-6 are not letters: NoteName rejects them and the queries below treat them as Letter::C.

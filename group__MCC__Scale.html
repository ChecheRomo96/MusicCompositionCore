Detailed Description

Scale patterns, spelled scales and the reviewed scale catalog.

MCC::ScalePattern stores up to twelve ascending degrees as diatonic steps and semitones above the root, built at compile time from a degree formula such as "1 2 b3 4 5 b6 b7". MCC::Scale spells a pattern from a root MCC::NoteName, so E major contains G#, never Ab. MCC::Scales holds the named catalog in program memory and reads it through Foundation::Utils::Flash, so on AVR neither patterns nor names occupy RAM. See Music-Domain Specification (SPEC-SCL-*).

const MCC::Scale dMinor =
MCC::Scales::Make(MCC::NoteName(MCC::Letter::D), MCC::Scales::Id::Minor);
MCC::NoteName sixth = dMinor.NoteAt(6); // Bb
MCC::Scales::Id id = MCC::Scales::Find("Aeolian"); // Id::Minor

Catalog and Provenance

Identifiers are stable. Every legacy definition comes from the historical MusicCompositionCore .Scale files under ScaleFlash/ScaleDefinitions; the OLD MCC tree and the copy vendored in the old MIDILAR repository carry the same semitone masks. Spellings are shown from C.

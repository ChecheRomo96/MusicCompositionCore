Detailed Description

Chromatic alteration of a letter, from -4 (quadruple flat) to +4 (quadruple sharp).

Natural (0) is a distinct written accidental (SPEC-ACC-1, SPEC-ACC-2). Default construction and out-of-range input produce the single invalid value (SPEC-ERR-1..3). Written order is by semitone value; the invalid value sorts after every valid accidental.

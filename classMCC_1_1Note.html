Detailed Description

A written pitch combined with an exact written note value.

Note preserves the pitch spelling (C#4 remains distinct from Db4) and the rhythmic spelling (base plus augmentation dots). Constructors that omit the note value use a quarter note. Invalid pitch or value input produces the single invalid note.

MIDI conversion deliberately does not live here: a MIDI note number has no written spelling. MIDILAR must provide a key or another spelling policy and then construct an MCC note from the resulting MCC::Pitch.

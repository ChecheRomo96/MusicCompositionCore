Detailed Description

Key signature: zero to seven sharps or flats (SPEC-KEY-1).

Stored as a signed position on the circle of fifths: positive values count sharps (F C G D A E B), negative values count flats (B E A D G C F). Values outside [-7, 7] produce the single invalid signature.

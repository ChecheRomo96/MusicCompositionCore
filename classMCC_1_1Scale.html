Detailed Description

A scale pattern spelled from a root note name.

Degrees are 1-based. Each degree is the root transposed by the pattern's interval, so spelling follows the pattern (SPEC-SCL-2): E major contains G#, never Ab. A degree whose spelling would need an accidental outside [-4, +4] is the invalid note name (SPEC-ACC-3, SPEC-SCL-3).

Membership is written by default (Contains) and enharmonic only on request (ContainsPitchClass), following SPEC-EQ-1..2.

Available examples:

Target Shows
MCC_Core_Version MCC and Foundation versions
MCC_Pitch_NoteNames Pitch classes of all 7 x 9 spellings, written equality versus enharmony, diatonic movement, boundary accidentals and written order
MCC_Interval_Intervals Intervals above C4, spelling-preserving transposition, intervals between pitches and inversions
MCC_Tuning_Pitches Octaves that belong to the letter, diatonic movement across octaves, written versus height order and frequencies under several tunings
MCC_Key_Keys Key signatures, the same sounds spelled in two keys, and text parsing and formatting
MCC_Chord_Chords Catalog chords with extensions, close-position inversions and the seventh chords of a scale
MCC_Scale_Scales Catalog scales spelled from several roots, written versus enharmonic membership and lookup by name or alias
MCC_Rhythm_NoteValues Named note values and augmentation dots as exact fractions of a whole note
MCC_Rhythm_Notes Four spelling-preserving note constructors, the default quarter value and copy-style pitch/value changes
MCC_Rhythm_Meters Simple, compound and irregular signatures, derived beats and written identity versus equal measure duration

Build and run one on the desktop:

./scripts/build.sh macos_arm64 --examples-on
./build/macos_arm64/bin/Debug/MCC_Tuning_Pitches_d

Enable and export Release examples with:

./scripts/export.sh macos_arm64 --fresh --examples-on
